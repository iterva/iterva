### 🚀 Proyecto destacado

#### [ShadowForge](https://shadow-forge-deck.vercel.app) — constructor de mazos para TCG
Aplicación fullstack para armar, guardar y compartir mazos de *Riftbound* y *Mitos y Leyendas*, nacida de mi propia afición por los juegos de cartas.

- **Frontend:** Angular 21 desplegado en Vercel
- **Backend:** Django + DRF con autenticación Google OIDC (id_token) + JWT
- **Modo offline:** catálogo descargable y búsqueda de cartas sin conexión
- **CI/CD:** GitHub Actions con ambientes de preproducción y producción

🔗 **Demo:** https://shadow-forge-deck.vercel.app
